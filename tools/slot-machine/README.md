# Slot machine

A slot machine any game can use: wheels of the same faces in their own order, clamps to keep wheels, a lever that pays and spins the others, a tray to take the prize, rolling reels that slow and stop one by one, and a computer player that picks the best expected move. Taken out of Οι Άποικοι (28 Nov 2026), where it was a jar's prize; parked here, not used by any game now.

- `slot-machine.js`: the machine (model, reels, plan, drawing). The game gives the faces, the win rule, the prize, how to draw a face, sounds and its clock; the model is written at the top of the file.
- `demo.html`: a working demo (open it in a browser).

Sound names it calls: `roll` (ticks as faces pass), `spin`, `stop`, `clamp`; the game plays its own `win`.
