# kid-games

A library of touchscreen HTML games with Greek settings, for a four-year-old.

- `games/<game>/`: one folder per game. Its `README.md` says what the game is, where its files are and how to run its checks.
- `docs/design-rules.md`: the game design rules (product, periods, tech, design sheet, process, status).
- `tools/ui-design/README.md`: the UI design guidelines. **Read them and follow them whenever you design or change anything a player sees or hears.**
- `tools/`: shared code (physics, cues) and tools.
- `CLAUDE.md`: how Claude works in this repo.
